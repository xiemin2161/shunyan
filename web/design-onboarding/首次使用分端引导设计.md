# 顺言首次使用引导（交互设计稿，2026-11-17）

## 本轮交付与边界

本轮重设计产品流程并提供可点击的电脑、手机设计稿，尚未替换正式设置页，未实现或执行驱动安装。设计稿中所有检测、连接及授权结果均为明确标注的演示。正式服务仍使用原8765端口、原配置及配对记录。

## 页面职责

- 自动识别当前设备，不显示自动识别、电脑、手机模式选择器。iPad需结合触摸能力判断；窗口变窄不等于手机。界面识别不构成权限校验，安装接口只允许经验证的本机管理请求。
- 电脑端只保留“界面设置 / 功能配置”。主题、图标、颜色、快捷键、录音方式、组件安装、配对设备管理、音频通路、Codex绑定均在电脑配置。
- 手机首次只展示安全连接、配对、麦克风授权和声音检查。完成后进入三键控制器；设置入口只管理当前电脑连接、证书引导和麦克风权限，不展示电脑配置。
- PC顶部显示连接状态和Codex状态，不显示证书状态。手机设置顶部显示证书验证、连接、Codex三项独立状态；Codex是可选能力，未接入不阻止语音使用。

## 电脑首次准备

| 步骤 | 用户操作 | “已完成”的实际依据 |
|---|---|---|
| 1 准备电脑 | 点击缺失项的“安装语音组件”，在系统窗口授权 | 音频库正常，虚拟播放与录音端匹配，格式受支持，通路可打开；安装器退出成功本身不足以完成 |
| 2 连接手机 | 展示二维码，手机完成安全连接、配对和麦克风授权 | 收到有效配对身份的在线心跳和本次授权结果；二维码被扫描不等于完成 |
| 3 声音检查 | 手机说一句话；按明确名称在闪电说中首次选择麦克风，确认识别文字 | 手机有效PCM到达主机，主机路由写入成功，并检查虚拟录音端信号；第三方识别由用户实际确认 |
| 4 完成 | 进入三键控制器或日常设置 | 前三项均通过，显示已完成摘要；Codex可稍后设置 |

未完成步骤禁用“下一步”。已完成步骤可以返回查看；返回不清除成果。首次引导完成后默认展示日常设置，重新检查只针对失效环节，不要求每次重走。多设备逐个保存名称、配对时间、最近连接及撤销状态，可新增、删除，撤销即时失效。

## 安装与自动配置

统一状态：待检查 → 待安装 → 下载中 → 等待系统授权 → 安装中 → 需要重启（如需） → 检测中 → 已完成。失败保留阶段和重试入口。进度写入主机私有设置，浏览器刷新或系统重启后重新检测并续接，不直接信任旧的完成标志。

Windows候选VB-CABLE；macOS候选BlackHole 2ch。组件只从官方来源获取，校验批准的版本、哈希及发布者；不得执行前端传来的任意URL或命令，不把未核实的静默参数写入实现。管理员授权和系统重启不能由网页绕过。

若检测到唯一且可用的目标通路，自动配置顺言自己的音频路由，不修改用户全局默认扬声器或麦克风。多条有效通路或用户已有自定义配置时，保留配置并提供异常处理入口。正常流程不让用户区分播放端、录音端。

闪电说尚无已验证的配置接口，因此只能明确引导一次选择对应录音端：Windows通常为CABLE Output，macOS为BlackHole 2ch。未经真实信号检查，不把名称相似的UU设备标记为手机麦克风，不宣称已经替第三方完成设置。

VB-CABLE基础包的再分发应保留官方许可并核查批量使用条件；其它付费扩展包不纳入。BlackHole的GPLv3与闭源分发许可需先确认，未解决前使用官方安装入口，不擅自打包。依据：[VB-CABLE](https://vb-audio.com/Cable/)、[许可说明](https://vb-audio.com/Services/licensing.htm)、[BlackHole官方仓库](https://github.com/ExistentialAudio/BlackHole)。

## 手机首次准备

1. 进入电脑提供的安全连接引导页，下载公开证书；根据iOS/Android显示对应说明。iOS描述文件安装和完全信任必须在系统设置完成，网页无法自动安装。
2. 返回后验证安全连接，再完成扫码配对。扫码链接含短期一次性凭证；日志和截图不得泄露凭证。
3. 由用户触发麦克风授权，采集真实音频并完成电脑声音检查，再进入控制器。

网页不能枚举系统证书仓库。证书卡可以分别显示“已确认安装”和“安全连接已验证”，不把HTTPS访问成功或下载完成单独解释为证书确已安装。权限拒绝时展示恢复入口；断线、切后台、锁屏时停止采集并释放长按映射键。

## 保留的日常能力

电脑功能配置维持四张等宽等高卡：电脑连接 / 按键与录音 / 手机语音 / Codex接入。快捷键通过实体键盘录制，支持左右修饰键及组合键；点按切换、长按说话均保留。Codex合并为一张卡，安装、真实连接状态、会话标题与绑定在一起。

界面设置保留已确认键帽及主题，缩略图复用实际样式与当前图标，可试按且不注入主机按键。整个键盘内文字、组件统一等比缩放。所有短暂交互反馈使用公共右上角浮层，不撑开正文。

## 实施验收门槛

- Windows和macOS分别检查未安装、授权取消、下载失败、重启恢复、已安装、路由冲突及通路中断；不得把原型演示当作通过。
- 手机完成真实授权，实际音频送到虚拟录音端，并在闪电说形成识别文字。iPhone/Android各实机验收，触控按压与PC效果一致。
- PC不显示移动证书设置，手机不显示主机安装和按键配置，服务端也拒绝手机调用主机管理接口。
- 更新替换8765原实例，备份并保留配对、证书、Codex绑定及用户配置，核对只有一个正式实例。
- 本轮仅完成设计稿流程演练和视觉评审；上述真实安装、跨平台和音频验收留待实施执行。

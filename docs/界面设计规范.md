# 界面设计与还原规范

本文件约束前台三键控制器和设置页的布局、比例、材质与验收。视觉参考为 [`前台键盘展示页设计稿`](../design/foreground-keyboard-page.png) 与 [`设置界面设计稿`](../design/settings-interface-v2.png)。页面中的设备由可交互 DOM/CSS 组件组成，屏幕状态、按键按下态和自定义图标不能被整图替代。

## 共用设备组件

### 桌面基准

- 外壳 `620 × 465 CSS px`，居中显示；可用视口较小时整块按单一比例缩小，视口更大时保持基准尺寸。
- 黑色状态屏宽约外壳的 `75%`、高 `32.5%`，上边距约 `8.5%`；保留银色外框、上沿微弱反光和下方软阴影。
- 三键组宽约外壳的 `85%`，高约 `35%`，从外壳顶边起约 `49.5%`；键帽等宽，中央对齐。
- 四颗螺丝使用独立 SVG 十字沉孔造型：圆形金属头、同心沉孔、凹陷十字槽和左上高光。上排中心距顶边约 `8.2%`，下排中心距顶边约 `88.5%`，左右距边约 `6.6%`。
- 键帽采用乳白实体倒角和短接触阴影。薄荷绿、天蓝、珊瑚色光集中在每颗键帽的下缘，不做围绕整键的宽泛光圈。

### 手机基准

- 外壳 `320 × 320 CSS px`，保持方形。三键面板的宽高、屏幕和键帽比例以该固定基准绘制；小视口只统一缩小整个组件。
- 屏幕宽约外壳的 `78%`、高约 `35%`，上边距约 `8.5%`；键组宽约 `85%`、高约 `31.5%`，顶边约 `53%`。
- 螺丝直径约 `17.5 px`；上排位置和左右边距与外壳成比例，下排中心约在外壳高度 `90%`。键帽、下沿和螺丝之间留出明确间隙。
- 手机规格字号按固定的手机基准设置，屏幕标题/说明/顶部标签约 `16/8/6 px`。更窄视口通过同一变换统一缩放字、键、屏幕、圆角和间隙。

### 材质和光影

- 面板为平滑的冷白半透明亚克力观感：外缘亮边、内沿细线、底边厚度和柔和投影；表面不加拉丝、斜纹或颗粒纹理。
- 状态屏是深色玻璃，圆角与外框细节保持克制；内容状态由实时数据驱动，数据不可用时如实显示离线/未知。
- 按键正面使用浅色半透明渐变、窄白色倒角和短接触暗影。背光只沿键帽底边扩散，颜色可以分别配置。
- 按下态只让键帽下移并加强接触阴影和底光；设备外壳、螺丝和屏幕位置保持不动。

## 设置入口齿轮

- 使用 `24 × 24` viewBox 的空心描边齿轮，八个齿以中心点均匀对称，齿根连续圆润，中心孔为正圆且透明。
- 描边 `1.8 px`，圆端点和圆角连接。可见尺寸 `22 × 22 px`，不拉伸、不偏心。
- 点击热区桌面至少 `48 × 48 px`，手机至少 `44 × 44 px`。图标在热区水平/垂直居中，并有“打开设置”的无障碍标签。

## 页面布局

- 前台页只显示设备和右上角设置入口；不显示配置表单、导航或状态事件列表。键帽只显示麦克风、勾选、叉号图标，不印文字。
- 设置页桌面使用左侧导航、设备预览和 Codex 状态区并列布局；映射、连接、外观仍可分别设置。
- 设置页手机使用顶部栏、设备预览、主机状态和底部导航。可滚动正文必须在底部导航和安全区上方留出空间。
- 配置保存、配对、断开和失败反馈使用固定的右上角中文浮层，不在正文插入提示行。

## 响应式行为

- 前台桌面 `1440 × 900` 与更大的 `1920 × 1080` 均保持 `620 × 465 px` 基准；增大视口只增加周边留白。
- 手机 `390 × 844` 使用 `320 × 320 px` 方形基准。若可视宽度不足，依 `visualViewport` 和根元素可视宽度计算同一缩小比例，确保两侧不裁切。
- 设置页的设备预览相对预览卡片缩至约 `85%`，并同时等比缩小内部文字、按键和螺丝。
- 不允许通过缩小文字来容纳更多内容；不得改变面板内的设计比例来适配浏览器窗口大小。

## 验收清单

- 在 `1440 × 900`、`1920 × 1080`、`390 × 844`、`320 × 700` 视口分别检查前台页；大屏组件不得放大或缩小，小屏组件必须完整居中。
- 检查四颗螺丝的十字槽方向、对称位置和金属高光；底部螺丝不得碰到键帽。
- 对照屏幕宽高、键组宽度、键帽圆角、底部彩色光、壳体边缘和阴影。表面不得出现斜纹。
- 检查设置入口齿轮八齿、圆孔、描边、居中和触控热区，并检查设置页手机导航不压住事件或文字。
- 检查空闲、按下、确认、取消和离线状态；交互不得改变设备布局。
- 至少由一位未参与当前 CSS 实现的设计角色独立复核手机和桌面截图；任何结构差异未解决前标记为 HOLD。

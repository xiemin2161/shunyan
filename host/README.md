# 本机服务开发说明

当前本机服务提供同源静态网页托管、一次性配对、配置读写、系统键盘事件、受限 PCM 音频转接和状态摘要 API。手机端采音前端及 Codex 实际状态源尚未接入；只有装有兼容的虚拟音频设备并明确选择输出端后，音频路由才可启动。

## 本机开发启动

在仓库根目录运行：

先安装本机音频后端依赖：

```powershell
python -m pip install -r host/requirements.txt
```

Windows PowerShell：

```powershell
python -m host.server
```

macOS 终端：

```sh
python3 -m host.server
```

默认仅监听 `127.0.0.1:8765`。桌面浏览器打开 `http://127.0.0.1:8765/` 可访问网页。启用局域网访问后，电脑本机请使用服务自己的绑定地址打开 `/pairing.html`，例如 `https://192.168.1.20:8765/pairing.html`；配对页读取当前有效码，点击“换一组”会调用 loopback/本机地址保护的轮换接口。其他局域网设备不能读取或轮换配对码。

手机访问前，需要在电脑的私有局域网 IP 上启动服务，并配置手机信任、且证书名称匹配服务绑定地址的 TLS 证书：

```powershell
python -m host.server --host 192.168.1.20 --port 8765 --tls-cert .\local-cert.pem --tls-key .\local-key.pem
```

服务拒绝绑定公网 IP、通配地址和组播地址。没有 TLS 时，局域网配对和持有令牌的控制请求会返回 `HTTPS_REQUIRED`；HTTP 只适用于本机预览。开发/发布启动器应以后使用 Windows 隐藏窗口启动方式或 macOS 登录项，当前没有启动后台进程。

音频转接将主机端 PCM 播放到设置页选定的虚拟音频播放端；语音软件需选择同一虚拟线对应的录音端。服务不会自动安装驱动，也不会默认向物理扬声器播放。Windows/macOS 均需先安装用户选择的虚拟音频设备，完整说明和验收仍在进行。

## 配置与数据边界

- 配置保存于当前用户配置目录，采用原子替换；配对会话令牌只保存在进程内存，服务重启后需重新配对。
- 配对码通过 loopback 或主机本机绑定地址读取/轮换；五分钟内有效、成功配对后立即失效，并按来源限速。
- 组合键由服务端依据已保存配置解析；修饰键先按下、主键后按下，按相反顺序释放。长按按键需要每秒续租，3 秒没有 press 续租就释放；toggle 语音在会话 6 秒无请求后发送一次 voiceStop。
- 本服务不写请求日志，不记录配对码、会话令牌、音频或 Codex 对话正文。

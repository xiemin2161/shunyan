# 后台两模块布局与验收契约

本轮由用户明确：后台只保留【界面设置】【功能配置】。沿用现有品牌、三键设备构图和已批准深按效果，不追加一级菜单或新概念。

## 桌面

左侧导航仅两项，当前项清晰可辨。主区顶部只显示当前模块标题与必要保存动作，不叠加多层面包屑。沿用项目字体、边框、表面和控件变量。

### 界面设置

- 主预览为第一对象，可试按三键；设备外围无方形底板、边框卡片或矩形图像背景补丁。机体与内部文字/图标一同等比缩放。
- 预览和主题选择在首屏相邻；主题以【玻璃】【凹面白】【哑光黑】三张真实效果缩略图展示，名称置缩略图下，选中有稳定标记。
- 图标以图形缩略图显示。主题固定自身材质与圆角，不再提供【整体风格】【键帽圆角】控件；禁止以同一示意图换文字充作不同主题。
- 三键选择与其图标、颜色编辑保持作用关系清楚，不把所有字段重复成三套冗长表单；若沿用三卡分组，标签必须明确且布局紧凑。
- 主题、图标、颜色变化立即反映在可试按主预览。主题/自定义切换不能留下旧图标、旧皮肤或重复光影。

### 功能配置

按使用顺序形成四组，组内紧凑、组间明确，不新增一级导航：
1. 手机连接：电脑显示连接二维码，证书提供直接下载；手机显示扫码/图片识别等连接入口。自动设备识别，手动切换为次要控件。
2. 按键：三键快捷键映射，明确支持组合键；语音模式为点按/长按，文字直述行为。
3. 音频：当前可用设备选择与真实状态；不可用时说明实际恢复条件。
4. Codex：安装组件动作与真实状态，不用“已就绪”占位冒充安装成功。

低频安装说明使用就地展开，不新增教程首页。避免把接口、进程、文件路径等实现细节写入日常产品操作文案。

## 手机

- 顶部是当前模块标题和必要连接状态，减少重复品牌/面包屑。
- 底部仅两项【界面设置】【功能配置】，保安全区；正文末尾动作可滚到完全可见，不被底栏遮挡。
- 界面页单列，设备预览先于主题；三主题缩略图优先同排，图标网格自适应但不缩成不可辨小图。
- 功能页优先连接，其他组纵向排列；不把桌面两列强挤入手机。
- 手机输入字号与点击区域可用；不能靠压小字体塞入内容。

## 共用交互规范

- 所有处理中、成功、失败提示使用固定右上角浮层，不撑正文。
- 下拉箭头与右边缘、文字有足够空间，复用项目自绘箭头控件。
- 保存、下载、安装、修复等业务动作使用中文文字按钮；图标辅助而不替代动作名。
- 预览试按不能误触发真实主机快捷键或录音；页面明确区分预览反馈和真实设备状态。

## 本轮独立验收清单

- 桌面与手机一级导航恰好两模块，无旧导航残留。
- 预览无方形底板、无矩形贴图边界，可完整试按并释放；按下不缩顶面或图标。
- 三主题、图标缩略图真实可辨，选中后主预览实时响应，切换恢复无残影。
- 颜色实时预览，保存后重新读取与当前值一致；失败反馈不移动布局。
- PC连接QR、手机扫码/证书直接下载按设备展示，未认证/未安装/未连接状态真实。
- 映射、点按/长按、音频选择、Codex组件操作仍可到达，未因归并导航丢失。
- 手机无横向溢出，底栏不盖按钮，箭头不贴边，业务动作使用文字按钮。

# 2026-11-16 补充：四面板与录入规范

功能配置在宽桌面采用2×2布局：电脑连接、按键与录音；音频设备、Codex接入。四张面板等宽等高，标题统一在卡片外。窄屏改为满宽单列自然高度。Codex会话状态与连接组件属于同一张卡片，不再绘制嵌套外卡。界面设置的桌面两列也使用等宽比例。

同一行输入框与操作按钮统一44px高度且顶边对齐；可读说明使用全部内容宽度，不保留280px等历史限制。处理中的图标为无底座的细线进度环，尊重减少动态效果设置。删除功能页顶端重复用途说明。

快捷键以实体键盘录入为主，不要求手输枚举；序列化保持现有平台键名，并区分左右修饰键。手机需要外接实体键盘。系统保留组合键可能无法由网页捕获，不能承诺支持全部系统快捷键。

会话选择展示真实标题、处理状态和当前项目标记；本机活动中的其他项目根对话应可分辨，编号仅辅助。数据读取受本机访问鉴权保护，不读取对话正文或认证文件。
